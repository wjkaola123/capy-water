# 卡皮补水站 · 设计与交互

以卡皮巴拉的温泉小院作为主场景。情绪价值来自有回应的陪伴，而不是连续打卡压力。

- 配色：雾白 `#f7f8f2`、鼠尾草 `#54764f`、嫩叶 `#e8eeda`、卡皮棕 `#cca074`、橘子黄 `#eea342`、温泉绿 `#83b39d`。
- 字体：跟随 iOS / Android 的系统中文字体，标题使用粗体；水量使用等宽数字。离线不依赖外部字体服务。
- 手机：品牌栏 → 日期问候 → 卡皮小院 → 回应气泡 → 今日水量 → 快捷记录；底部四栏导航。
- 平板 / 桌面：小院与记录为主栏，今日水量、提醒、心情与周趋势为侧栏；宽屏使用固定侧边导航。
- 插画为 React Native SVG 原创矢量场景，可直接在原生渲染，不依赖图片网络请求。主插画、头像和装扮共用角色组件。
- 动画：卡皮漂浮与轻摆、眨眼、温泉蒸汽、摸头 / 喝水爱心、进度环缓动、按钮弹性反馈。原生平台使用可用的 native driver；Web 使用 JS driver。
- 达标后提示按口渴感喝水；断开记录不惩罚。装扮以已保存的真实记录数解锁，花园植物随 1 / 5 / 12 杯记录成长。
- 保留明显的输入错误、保存失败与通知权限提示，情绪文案不遮盖操作结果。

原市集实现保存在 `legacy/market-expo/`；更早的 Capacitor 项目保存在 `legacy/capacitor/`。
